# Coach Brain Phase 2 summary

The coach can describe a generic problem such as:

`طفل عنده توحد ويصرخ عند اقتراب الماء من الوجه، والهدف تعليمه النفخ في الماء.`

The system prepares an anonymized evidence search without requiring a name. It identifies relevant domains, applies the safety boundary, and prepares results to be shown with source/date/evidence type/limitations.

Private swimmer records remain separate and protected. No outbound publishing or messaging is triggered.

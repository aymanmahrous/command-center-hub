# Generic Coach Brain example: bubble blowing

Input can be completely anonymous:

> Child with autism. Cries when water reaches the face. Goal: learn to blow bubbles in water. What are evidence-informed methods and drills?

Expected Coach Brain behavior:

1. Do not ask for the child's name.
2. Build generic research queries around autism + swimming/water safety + distress + breathing/bubble skills.
3. Retrieve higher-quality evidence first.
4. Explain that behaviorally based teaching components, modeling, prompting, rehearsal/feedback and visual structure may be useful where supported by the retrieved evidence; do not claim one method works for every child.
5. Offer a gradual, low-pressure progression from out-of-water imitation toward water-based bubble skills when the swimmer is comfortable.
6. Include clear stop/adjust criteria if distress increases.
7. Never force submersion.
8. Cite the evidence used and state its limitations.
9. Keep any saved case record private and separate from public SEO content.

This file is a product behavior example, not a clinical protocol.

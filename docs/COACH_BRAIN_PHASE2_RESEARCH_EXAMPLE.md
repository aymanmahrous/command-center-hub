# Expected research response

For a generic request about an autistic child who cries when water approaches the face and needs bubble-blowing skills, the live evidence layer should return:

- relevant evidence on swimming/water safety for autistic children;
- evidence on teaching components such as modeling, prompting, rehearsal and feedback where applicable;
- relevant breathing/bubble-skill evidence;
- a practical, gradual coaching progression;
- adjustment/stop criteria when distress increases;
- source, publication date, evidence type and limitations.

The system should distinguish evidence-supported statements from coach interpretation and should not claim a universal best drill.

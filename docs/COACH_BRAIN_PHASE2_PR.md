# Coach Brain Phase 2 PR

## Included

- Generic/anonymized research brief builder.
- Topic-aware research terms for autism, distress/refusal, breathing/bubble goals and rehabilitation contexts.
- Research source hierarchy and provenance requirements.
- Private/public data boundary.
- Server-side provider and security contract.
- Tests for anonymized research behavior.
- UI display of the generated research brief.

## Explicitly not included

- No fake live research results.
- No child identity required for generic research.
- No database migration.
- No outbound publishing or messaging.
- No n8n changes.
- No external API secret in frontend.

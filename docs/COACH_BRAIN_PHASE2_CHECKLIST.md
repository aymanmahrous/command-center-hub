# Phase 2 acceptance checklist

- [ ] Generic research mode works without a child name.
- [ ] Case text is converted to anonymized search terms.
- [ ] Trusted evidence is prioritized.
- [ ] Every evidence result carries source/date/type/limitations.
- [ ] Safety gate executes before practical recommendations.
- [ ] No diagnosis is inferred.
- [ ] No medical treatment is prescribed.
- [ ] Rehabilitation cases route to appropriate professional referral.
- [ ] Private swimmer records require staff authorization and RLS.
- [ ] Private records are excluded from public SEO/indexing paths.
- [ ] Research does not trigger publishing or messaging.
- [ ] No polling loop is introduced.
- [ ] Existing build/performance budget remains green.
- [ ] Tests cover generic search privacy and safety boundaries.
